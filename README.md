# Neha Bhati — Portfolio

A responsive, static portfolio website. It does not contain or upload your CV.

## Deploy on GitHub Pages
1. Create a new public GitHub repository named `neha251723.github.io` (or any repository name).
2. Upload `index.html` and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Wait for GitHub Pages to publish. Your site URL will be shown in the Pages settings.

If you use a repository other than `neha251723.github.io`, the URL will usually be:
`https://neha251723.github.io/REPOSITORY-NAME/`
